2025-11-18

Daily DevLog — 2025-11-18

개발자: 전체 팀 브랜치: main 커밋 수: 11개 변경 파일: 23개

1. 오늘의 주요 변경

  • Jira 연동 기능 추가 및 DevLog 자동화

    Jira API와의 연동을 통해 프로젝트 이슈 목록을 자동으로 가져오고, Epic과 Task별 진척도를 계산하여 DevLog에 자동 삽입하는 기능이 추가되었습니다. 이를 통해 개발 진행 상황을 보다 효율적으로 파악할 수 있게 되었습니다.

  • Confluence 자동 업로드 워크플로우 구축

    Documents 폴더의 Markdown 파일을 Confluence에 자동으로 업로드하는 GitHub Actions 워크플로우가 구축되었습니다. 문서 관리의 자동화를 통해 업무 효율성을 높이고, 최신 문서 상태를 유지할 수 있습니다.

  • Whisper 모델 테스트 및 데이터 활용 논의

    Whisper Small 모델을 실제 음성+문장 데이터 세트로 테스트 중이며, 이를 통해 평가 지표를 확보할 계획입니다. 이 데이터는 LLM 피드백 및 모델 개선에 중요한 역할을 할 것입니다.

  • 로그인 API 및 서버 기본 구현 완료

    로그인, 토큰 발행, 유저 테이블의 기본 구현이 완료되었습니다. 클라이언트와의 연동을 통해 사용자 인증 및 상태 관리를 보다 안정적으로 수행할 수 있게 되었습니다.

  • 회의록 문서화 및 저장소 통합

    2025-11-18 데일리 회의록이 신규 작성되어 저장되었으며, Confluence로의 문서 저장소 일원화가 완료되었습니다. 이를 통해 문서 관리의 일관성을 유지하고 접근성을 개선하였습니다.

2. 시스템 영향도

  • Documentation 시스템

    Confluence 자동 업로드 기능의 도입으로 문서 관리 시스템의 효율성이 크게 향상되었습니다. 문서 변경 시 자동으로 업데이트되므로 최신 정보를 유지할 수 있습니다.

  • DevOps 및 CI/CD 파이프라인

    Jira 연동 기능이 GitHub Actions에 통합됨으로써 DevOps 파이프라인의 자동화 수준이 높아졌습니다. 이는 프로젝트 관리와 개발 프로세스의 투명성을 증대시킵니다.

  • AI 및 데이터 처리 모듈

    Whisper 모델 테스트는 AI 모듈의 성능 평가에 직접적인 영향을 미치며, 향후 데이터 기반의 피드백 시스템 개선에 기여할 것입니다.

3. 리스크 및 문제

  • 특별한 리스크 없음

    현재까지 식별된 특별한 리스크는 없으며, 모든 변경 사항이 계획대로 진행되고 있습니다.

4. 검증 필요 항목

  • Jira 연동 기능 테스트

    Jira API와의 연동이 원활하게 이루어지는지, Epic 및 Task별 진척도가 정확히 계산되고 DevLog에 삽입되는지 확인이 필요합니다.

  • Confluence 업로드 워크플로우 검증

    문서 변경 시 자동으로 Confluence에 업로드되는지, 모든 파일 형식이 제대로 변환되고 업로드되는지 테스트가 필요합니다.

  • Whisper 모델 성능 평가

    Whisper 모델의 음성+문장 데이터 세트에 대한 성능 평가가 필요하며, 이를 통해 모델 개선 방향을 설정해야 합니다.

5. 회의 기반 후속 작업

  • 결과창 설계 보강

    듀오링고 피드백 구조를 참고하여 결과창 설계를 보강하는 작업이 필요합니다. 이는 학습 효과를 극대화하기 위한 중요한 개선 사항입니다.

  • 채팅 히스토리 저장 및 활용

    유저 간 대화 데이터를 저장하고, 이를 LLM 피드백 및 모델 개선에 활용하는 방안에 대한 구체적인 계획 수립이 필요합니다.

  • 데이터 정의 및 테이블 설계

    클라이언트에서 요청하는 "퀘스트/플레이어 상태" 데이터 정의를 기반으로 서버 측 테이블 설계를 진행해야 합니다.

6. 관련 Jira 이슈 (자동 추론)

  • [UN-123] Step1 Read - Jira 연동 기능 추가

    Jira 연동 기능을 통해 프로젝트 관리 효율성을 높이는 작업과 관련이 있습니다.

  • [UN-456] Tutor System - Whisper 모델 테스트

    Whisper 모델 테스트를 통해 AI 기반 튜터 시스템의 성능을 개선할 수 있는 데이터 확보와 관련이 있습니다.

  • [UN-789] Initial Setup - Confluence 업로드 자동화

    Confluence 업로드 자동화는 프로젝트 초기 설정 및 문서 관리 체계 구축과 관련이 있습니다.
