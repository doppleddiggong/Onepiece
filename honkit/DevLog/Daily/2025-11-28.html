Daily DevLog — 2025-11-28

개발자: 전체 팀 브랜치: main 커밋 수: 20개 변경 파일: 107개

1. 오늘의 주요 변경

  • 훅 시스템 물리 및 충돌 처리 개선: 훅 시스템에서 대상 오브젝트를 끌어올릴 때 물리 시뮬레이션과 충돌을 비활성화하여 부드럽고 방해 없는 이동을 구현했습니다. 이는 사용자 경험을 향상시키고, 훅 해제 시 원래 상태로 복원되도록 하여 안정성을 높였습니다.

  • 캐리어 정보 위젯 초기화 개선: 캐리어의 색상과 패턴 정보를 UI 위젯에 정확히 초기화하고 표시하도록 변경했습니다. Tick 함수 내에서 지연 초기화 방식을 적용하여 정보 반영 속도를 개선했습니다.

  • 인터뷰 팝업 시스템 구현: 서버로부터 받은 인터뷰 질문 데이터를 팝업으로 표시하고, 사용자가 답변을 입력할 수 있는 기능을 구현했습니다. 이를 통해 인터뷰 콘텐츠를 효과적으로 관리할 수 있는 기반을 마련했습니다.

  • 결과 팝업 타입 추가 및 매핑 설정: 결과 팝업을 새롭게 도입하면서 이를 관리하는 팝업 타입과 클래스 매핑을 추가했습니다. 이를 통해 결과 팝업을 기존 시스템에 통합하여 활용할 수 있도록 개선했습니다.

  • 인터랙션 위젯 표시 로직 활성화: 인터랙션 시작과 종료 시 위젯이 정상적으로 표시되고 사라지도록 수정하여 사용자 경험을 개선했습니다.

2. 시스템 영향도

  • UI 시스템: 캐리어 정보 위젯 및 인터뷰 팝업 시스템의 변경으로 UI 구성 요소가 개선되었습니다. 이는 사용자 인터페이스의 일관성과 반응성을 높이는 데 기여합니다.

  • 물리 시스템: 훅 시스템의 물리 및 충돌 처리 개선은 물리 시뮬레이션의 안정성을 높이며, 게임 내 상호작용의 자연스러움을 증가시킵니다.

  • 데이터 관리 시스템: 결과 팝업 타입 추가 및 매핑 설정은 데이터 구조의 확장을 통해 시스템의 유연성을 높입니다.

3. 리스크 및 문제

  • 잠재적인 문제점: 인터뷰 팝업 시스템이 서버와의 통신에 의존하기 때문에 서버의 응답 속도나 데이터 형식에 따라 문제가 발생할 수 있습니다.
  • 기술적 부채: UI 위젯의 초기화 로직이 복잡해질 수 있어 향후 유지보수 시 어려움이 발생할 수 있습니다.

4. 검증 필요 항목

  • 훅 시스템: 물리 시뮬레이션과 충돌 처리 개선 후의 동작 검증 필요.
  • 인터뷰 팝업: 팝업의 질문 리스트 생성 및 답변 제출 기능의 정상 작동 여부 확인.
  • UI 위젯: 캐리어 정보 위젯의 초기화 및 표시 로직 검증.

5. 회의 기반 후속 작업

  • API 통합 및 문서화: 회의에서 논의된 API 문서 자동 생성 가능성에 대한 후속 작업이 필요합니다. API 기준 정리 작업도 진행 예정입니다.
  • Step1 안정화: 플레이 흐름 정리 완료에 따라 추가적인 테스트 및 안정화 작업이 필요합니다.

6. 관련 Jira 이슈

  • [UN-466] 음량(dB) 게이지 표시 - UI 시스템의 변경과 관련하여 음량 표시 기능의 통합이 필요합니다.
  • [UN-465] 녹음 가이드(문장을 먼저 듣고 말하세요) - 인터뷰 팝업 시스템과 관련하여 사용자 경험을 향상시키기 위한 작업입니다.
  • [UN-400] 녹음/STT/대화 - 인터뷰 팝업 시스템의 데이터 수집 기능과 관련이 있습니다.
  • [UN-426] 문 Replicate(서버 권한) - API 통합과 관련된 작업으로, 서버와의 통신 안정성을 높이는 데 기여할 수 있습니다.
