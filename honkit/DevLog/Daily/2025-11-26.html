Daily DevLog — 2025-11-26

개발자: 전체 팀 브랜치: main 커밋 수: 41개 변경 파일: 210개

1. 오늘의 주요 변경

  • UI 공통 버튼 스타일 완성: Hover 및 Pressed 상태를 포함한 UI 공통 버튼 3종을 완성하였으며, 모든 팝업에서 신규 버튼 스타일로 교체할 예정입니다. 이는 사용자 경험을 향상시키기 위한 작업입니다.

  • 캐리어 색상 변경 기능 구현: 캐리어의 색상 변경 기능이 구현 완료되었습니다. 이를 통해 사용자 맞춤형 설정이 가능해졌습니다.

  • Step1 플레이 흐름 구성: 매대 배치와 관련된 Step1의 플레이 흐름을 구성하였습니다. 이는 게임의 초기 단계에서 사용자 경험을 개선하기 위한 작업입니다.

  • 시나리오 API 연동 완료: 시나리오 API와의 연동이 완료되었으며, 팝업 출력 기능과의 연계 작업이 예정되어 있습니다. 이는 게임의 시나리오 진행을 매끄럽게 하기 위한 조치입니다.

  • 인터뷰 질문 데이터 생성: 약 200개의 인터뷰 질문 데이터가 생성되었으며, 상/중/하 및 면세 영역을 포함한 30여 개의 질문이 추가되었습니다. 이는 LLM 검증을 위한 기초 데이터로 활용될 예정입니다.

2. 시스템 영향도

  • UI 시스템: 새로운 버튼 스타일 적용으로 인해 UI 시스템 전반에 걸쳐 일관된 사용자 경험을 제공할 수 있게 됩니다.
  • 게임 흐름 시스템: Step1의 플레이 흐름 구성은 게임의 초기 단계에서의 사용자 경험을 개선하며, 매대 배치와 관련된 로직에 영향을 미칩니다.
  • API 연동 시스템: 시나리오 API와의 연동은 게임의 시나리오 진행과 관련된 모든 팝업 출력에 영향을 미치며, 사용자 인터페이스와의 통합이 필요합니다.
  • 데이터 관리 시스템: 인터뷰 질문 데이터의 생성은 LLM 검증 시스템에 직접적으로 영향을 미치며, 데이터의 정확성과 품질을 보장해야 합니다.

3. 리스크 및 문제

  • 잠재적인 문제점: 새로운 UI 버튼 스타일이 기존 시스템과의 호환성 문제를 일으킬 수 있으며, 모든 팝업에서의 일관된 적용이 필요합니다.
  • 기술적 부채: 인터뷰 질문 데이터의 품질 관리 및 LLM 검증 구조에 대한 논의가 필요하며, 이와 관련된 기술적 부채가 존재합니다.
  • 특별한 리스크 없음: 현재로서는 특별한 리스크가 발견되지 않았습니다.

4. 검증 필요 항목

  • UI 버튼 스타일 검증: 새로운 버튼 스타일이 모든 팝업에서 일관되게 적용되는지 확인해야 합니다.
  • Step1 플레이 흐름 테스트: 매대 배치와 관련된 Step1의 플레이 흐름이 정상적으로 작동하는지 검증이 필요합니다.
  • 시나리오 API 연동 검증: API 연동이 정상적으로 작동하며, 팝업 출력 기능이 제대로 연계되는지 확인해야 합니다.
  • 인터뷰 질문 데이터 검증: 생성된 인터뷰 질문 데이터의 품질과 정확성을 검증해야 합니다.

5. 회의 기반 후속 작업

  • UI 버튼 스타일 교체 작업: 회의에서 논의된 UI 공통 버튼 스타일 교체 작업이 진행 중입니다.
  • Step1 플레이 흐름 구성: 매대 배치와 관련된 Step1의 플레이 흐름이 구성되었으며, 후속 검증이 필요합니다.
  • 시나리오 API 연동 작업: API 연동이 완료되었으며, 팝업 출력 기능과의 연계 작업이 예정되어 있습니다.
  • 인터뷰 질문 데이터 생성: 약 200개의 인터뷰 질문 데이터가 생성되었으며, LLM 검증을 위한 기초 데이터로 활용될 예정입니다.

6. 관련 Jira 이슈

  • [UN-462] LLM 평가(JSON Score) - 인터뷰 질문 데이터 생성과 관련하여 LLM 검증을 위한 기초 데이터로 활용될 예정입니다.
  • [UN-400] 녹음/STT/대화 - 시나리오 API 연동과 관련된 기능으로, 팝업 출력 기능과의 연계가 필요합니다.
  • [UN-403] STT/TTS/OCR/LLM - 인터뷰 질문 데이터와 관련된 LLM 검증 작업과 연관되어 있습니다.
