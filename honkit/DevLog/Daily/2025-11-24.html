Daily DevLog — 2025-11-24

개발자: 전체 팀 브랜치: main 커밋 수: 34개 변경 파일: 2916개

1. 오늘의 주요 변경

  • 마스터 데이터 구조체 및 데이터 매니저 기능 추가

    한국어 학습 게임의 마스터 데이터를 체계적으로 관리하기 위해 여러 데이터 구조체를 정의하고, 이를 관리하는 게임 데이터 매니저 기능을 구현했습니다. 색상, 레벨, 듣기, 읽기, 단어 학습 데이터 등 다양한 학습 관련 정보를 효율적으로 처리할 수 있도록 준비했습니다.

  • 컨베이어 벨트 이동 로직 및 머티리얼 흐름 구현

    UV panner를 이용하여 컨베이어 벨트의 이동 로직을 구현하고, overlap된 액터와 컴포넌트를 통해 이동시키는 기능을 추가했습니다. 이는 게임 내 물리적 상호작용을 보다 자연스럽게 만들기 위한 개선입니다.

  • 온라인 세션 시스템 및 로비 UI 구현

    멀티플레이어 세션 관리 기능을 ULingoGameInstance에 추가하여 세션 생성, 검색, 참여 기능을 지원합니다. Steam/LAN 자동 감지 및 지원을 통해 다양한 네트워크 환경에서의 멀티플레이어 경험을 강화했습니다.

  • 로그인 및 토큰 기반 인증 시스템 구현

    사용자 인증 플로우를 완성하여 로그인과 회원가입 후 자동 로그인을 지원합니다. 사용자 토큰 발급 기능을 통해 보안성을 높이고, 로비맵으로 자동 전환되도록 하여 사용자 경험을 개선했습니다.

  • 게임 진행 타이머 및 UI 위젯 연동 구현

    게임 내 미션 진행 시간을 관리하는 타이머 기능을 GameState에 추가하고, 이를 UI 위젯과 연동하여 플레이어에게 남은 시간을 실시간으로 보여주도록 개선했습니다. 이는 사용자에게 명확한 게임 진행 정보를 제공하기 위한 것입니다.

2. 시스템 영향도

  • 데이터 관리 시스템

    마스터 데이터 구조체 및 데이터 매니저 기능 추가로 인해 데이터 관리의 효율성이 증가했습니다. 이는 게임 내 다양한 학습 데이터를 체계적으로 관리하고, 빠르게 조회할 수 있게 합니다.

  • 네트워크 및 멀티플레이어 시스템

    온라인 세션 시스템 구현으로 멀티플레이어 기능이 강화되었습니다. 이는 다양한 네트워크 환경에서의 안정적인 멀티플레이어 경험을 지원합니다.

  • UI 및 사용자 경험

    로그인 및 인증 시스템, 게임 진행 타이머 UI 연동으로 사용자 경험이 크게 향상되었습니다. 이는 사용자에게 명확한 인증 절차와 게임 진행 정보를 제공하여 게임의 몰입도를 높입니다.

3. 리스크 및 문제

  • OCR 문제(500 에러)

    OCR 테스트 중 500 에러가 발생하여 서버 측에서 원인 확인이 필요합니다. 이는 OCR 기능의 안정성을 저해할 수 있는 잠재적 리스크입니다.

  • 이미지 전송 규격 논의

    OCR 이미지 전송 방식에 대한 논의가 필요합니다. 글자 단위로 묶어 전송하는 구조와 한 문장 단위 이미지 전송 방식 간의 최적화가 필요합니다.

4. 검증 필요 항목

  • OCR 기능 안정성 테스트

    OCR 기능의 500 에러 원인을 파악하고, 다양한 파일 형식 및 크기에 대한 테스트가 필요합니다.

  • 멀티플레이어 세션 기능 테스트

    다양한 네트워크 환경에서의 세션 생성, 검색, 참여 기능의 안정성을 검증해야 합니다.

  • 게임 진행 타이머 UI 연동 테스트

    타이머 기능이 UI 위젯과 제대로 연동되어 실시간으로 남은 시간을 정확히 표시하는지 확인해야 합니다.

5. 회의 기반 후속 작업

  • 스텝1 개발 목표

    이번 주 수요일까지 Step1(읽기 기반 수하물 식별)을 완전히 플레이 가능 상태로 만드는 것이 목표입니다. 트리거 박스, 쪽지 POPUP, 단어장, 캐리어 식별, 상호작용 흐름 구현이 필요합니다.

  • 시나리오 데이터 기반 문제 해결

    시나리오 데이터는 테이블 번호 기반으로 변경이 필요하며, 클라이언트에서 처리 불가한 한글 기반 심볼/컬러는 모두 숫자 인덱스로 통일해야 합니다.

6. 관련 Jira 이슈 (자동 추론)

현재 조회된 Jira 이슈는 없습니다. 커밋 메시지와 변경 파일을 기반으로 관련 이슈를 추론할 수 없었습니다. 향후 Jira 이슈와의 연관성을 명확히 하기 위해 커밋 메시지에 관련 이슈 키를 포함하는 것이 좋습니다.
