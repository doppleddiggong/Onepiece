2025-11-24 데일리 회의

1. 개요

  • 일자: 2025-11-24
  • 참석: 배주백, 박종욱, 전민우, 이재진, 이치훈, 김한호, 이영훈
  • 키워드: 스텝1, OCR 오류(500), 이미지 전송 규격, 인터뷰 질문지, 캐릭터/컬러 시스템, 시나리오 데이터 매핑, 프로토타입 품질 요구

2. 논의 요약

2.1. 주요 논의

  • 스텝1 개발 목표:

    • 이번 주 수요일까지 Step1(읽기 기반 수하물 식별)을 완전히 “플레이 가능 상태”까지 끌어올리는 것이 팀 공통 목표.
    • 트리거 박스 → 쪽지 POPUP → 단어장 → 캐리어 식별 → 상호작용 흐름 구현 예정.

  • 협동 플레이 기획:

    • 현재 명확한 기획 확정 없음.
    • Step1 우선 완성 후 Step2/3/4 구간에서 자연스러운 협업 패턴을 고려.

  • 시나리오 데이터 기반 문제:

    • 데이터는 테이블 번호(숫자 인덱스) 기반으로 변경 필요.
    • 한글 기반 심볼/컬러는 클라이언트 처리 불가하여 모두 숫자 인덱스로 통일.

  • 스텝1/2 시나리오 데이터 구성:

    • Step1·2용 데이터는 이번 주 안에 서버에서 확정 예정.
    • Step3(쓰기) 진입 전 인터뷰 질문지 API가 필요.

2.2. 기술 / 기획 관련 논의

  • OCR 문제(500 에러):

    • 초반에는 정상 동작했으나 여러 파일 테스트 중 500 발생.
    • 서버 측에서 원인 확인 예정.

  • OCR 이미지 규격 논의:

    • 글자 단위(360px)로 묶어 전송하는 구조 vs 한 문장 단위 이미지 전송
    • 이미지 여러 장 전송(문항 당 1장)으로 합의
    • 글자 너비/크기/해상도 조정 필요
    • 랜더 타겟이 고정 1280x720으로 저장된다는 제약 존재

  • 쓰기 UI:

    • 필기 보드에서 지우개 기능 완료
    • 글씨 크기 변경 → 버그 → 해결
    • Step1 컨베이어/캐리어 움직임 구현 예정

  • TTS:

    • 듣기 시나리오용 TTS 음성 생성 API 개발 진행 예정

  • 인터뷰 질문지 설계:

    • 로그인 직후 관심사 기반 질문 1~3개 수준이 적정
    • LLM 기반으로 질문 생성
    • 질문→쓰기 단계에서 사용되는 데이터로 활용

  • 캐릭터/스토어 구성:

    • 아바타 외형·색상은 비용 없이 기본 선택 가능
    • 스토어는 장비류 중심으로 구성
    • 외형/컬러는 스토어 항목에서 제외
    • 트랜잭션 처리는 추후(알파 후반)

  • 시나리오 관리 페이지:

    • 시나리오/스테이지 구성을 ID(숫자) 기반으로 관리
    • 문자열 기반 타이틀은 문제 가능성 있어 인덱스 우선

2.3. 일정 / 운영 관련 논의

  • 프로토타입 완성도 요구:

    • 최종 프로젝트 특성상 “단순 프로토타입”이 아니라 거의 베타 수준의 완성도 필요
    • 회의 시간 최소화 → 개발 집중

  • 주요 마일스톤:

    • Step1: 이번 주 수요일까지
    • Step2/3/4: Step1 완료 기반 확장
    • 서버 측: 시나리오 1·2 데이터 확정, 관리 페이지 제작
    • 클라 측: 팝업 시스템·필기보드·컨베이어·상호작용 처리
