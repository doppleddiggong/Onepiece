251203 Daily

2025-12-03 데일리 회의

1. 개요

  • 일자: 2025-12-03
  • 참석: 배주백 외 팀원
  • 키워드: 리슨 오디오, 오디오 캐싱, OCR, 시나리오 합치기, 최종 평가, 프로토 목표

2. 논의 요약

2.1. 주요 논의

  • 리슨 오디오/스피크 기능 연동 완료 및 오디오 캐싱 매니저 구현

    (반복 요청으로 서버 토큰 소모 문제 해결)
  • UE5 무비 패널: mp4 스트리밍 불가 → 사전 캐싱한 mp4 목록에서 재생하는 방식으로 결정
  • 쓰기/말하기 시나리오 문서 완성 → 시나리오 병합 후 서버 반영 필요
  • OCR → 서버 연동 방식 점검 필요

    · 질문·단어 묶음 전송 / 단일 전송 방식 비교

    · OCR Extract API 구조 확인 필수

2.2. 기술 / 기획 관련 논의

  • 최종 평가 화면은 템플릿 미정 → 1차 버전은 스크롤 텍스트 기반 임시 출력으로 진행
  • 키오스크 기반 쓰기 UI 완성

    질문 길이에 따라 입력칸 확장 기능 검토
  • 듣기 시나리오 일부 구간을 공항 외부(버스표·푸드코트 등)로 이동하는 방향 검토

2.3. 일정 / 운영 관련 논의

  • 목요일까지 핵심 기능 마무리 목표
  • 금요일 아침에는 API 정리 완료 상태 목표
  • 프로토 목표는 “API 교통 + 플레이 가능성 검증”

    (정교한 점수/피드백은 알파 이후)
  • 일부 팀원은 내일 오후 면접 일정으로 부재 예정

3. Action Items

클라이언트 팀

  • [ ] 듣기/쓰기/말하기 시나리오 병합 및 반영 (담당: 팀원, 기한: 12/04)
  • [ ] OCR 네트워크 연동(Extract API 구조 검증 포함) (담당: 팀원, 기한: 12/04)

AI 팀

  • [ ] 말하기(STT + 평가 에이전트) 연동 및 응답 JSON 샘플 전달 (담당: 팀원, 기한: 12/04)
  • [ ] 최종 평가 보고서 포맷 초안 및 출력 JSON 샘플 공유 (담당: 팀원, 기한: 12/04~12/05)

DevOps / 전반

  • [ ] 서버 반영 후 Redis 저장 구조 점검 (현재 시나리오 상태/대기 상태 관리) (담당: 팀원, 기한: 12/04)

4. 회고

4.1. 잘된 점 (Keep)

  • 리슨/스피크 등 핵심 음성 기능이 안정적으로 붙기 시작함
  • 키오스크 기반 UI 완성 → 시나리오 구현 속도 증가
  • API/서버/클라 협업 효율 상승

4.2. 미진한 점 (Problem)

  • OCR 연동 사양이 불명확하여 서버-클라 연결 논의 지연
  • 최종 평가 화면 포맷이 확정되지 않아 설계 지연 발생

4.3. 다음 단계 (Try)

  • OCR Extract API 명세 확정 후 프로토콜 고정
  • 프로토는 최소 기능(학습-결과-플레이 가능성) 기준으로 맞추고

    시각화/정교한 점수는 알파 이후로 이동
  • 듣기/쓰기/말하기 시나리오 개편 내용 문서화하여 전체 흐름 명확히 공유
