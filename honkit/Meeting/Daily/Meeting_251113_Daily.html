251113 Daily

2025-11-13 데일리 회의

1. 개요

  • 일자: 2025-11-13
  • 참석: 전 팀 전체
  • 키워드: OT(온보딩), 캐릭터 외형, 시나리오, DevOps, 커밋 메시지 자동화, Base64, RAG, VectorDB, 지라, Confluence, Flow

2. 논의 요약

2.1. 주요 논의

  • OT 기간 동안 신규 멤버는 실제 작업을 통해 역할과 강점을 파악하도록 하고, 야간·주말 작업은 화면 공유 등 투명성 확보를 전제로 운영하기로 함.
  • 입국 절차/택시/호텔/식사/관광을 잇는 시나리오를 중심으로 읽기-쓰기-말하기 흐름을 짜고, 아스트로봇 계열 플레이어와 거대 NPC의 캐릭터 품을 정리함.
  • 토이 프로젝트 Flow를 본 프로젝트 플로우로 전환해 실질적인 문서화와 시연 준비에 활용하고, 오늘 오후부터 본 프로젝트 Flow 작업 진행.

2.2. 기술 / 기획 관련 논의

  • Base64 통일 데이터를 기준으로 이미지·음성(STT/TTS) 송수신을 설계하며, API 스펙을 문서화하기 위한 자료를 정리 중.
  • GPT 외 한국어 특화 로컬 모델과 VectorDB 기반 RAG 구조를 병행 검토하여 법률/규정 등 변동성이 큰 데이터와 웹서치 기반 콘텐츠를 명확히 분리.
  • 클라이언트는 시퀀스/씬 플로우와 커밋 자동화, AI 팀은 Whisper STT/TTS 테스트 및 API 문서화 초안을 준비하며 협업 선순환을 구축.

2.3. 일정 / 운영 관련 논의

  • 내일 시나리오 기반 브리핑과 클라이언트·AI 합동 검토를 진행하고, 주말에는 PPT/Flow 다이어그램과 시나리오 비주얼 작업에 집중.
  • 월요일 교수님 리뷰 및 기술 설계 1차 완성, 화요일 발표를 목표로 오전까지 초안 완성하여 발표 준비.
  • 오늘 오후 DevOps 세팅(커밋 메시지 자동화, 지라/컨플루언스 연결)을 마무리하고, API/Flow 문서는 주말 동안 통합 정리.

3. Action Items

클라이언트 팀

  • [ ] 입국 절차/호텔/주문 중 하나를 중심으로 시나리오 Flow를 완성 (담당: 클라이언트 팀, 기한: 2025-11-14)
  • [ ] 캐릭터 외형·역할 정의 및 글쓰기/색상/선택 인터랙션 프로토타입 작성 (담당: 아트·클라이언트, 기한: 2025-11-15)
  • [ ] Base64 기반 API 샘플 데이터 송수신 구조 문서화 (담당: 클라이언트, 기한: 2025-11-16)

AI 팀

  • [ ] Whisper STT + TTS 연동 테스트 및 로컬 한국어 모델 후보 검토 (담당: AI 팀, 기한: 2025-11-15)
  • [ ] VectorDB 기반 RAG 구조와 API 프로토콜 문서화 초안 작성 (담당: AI 팀, 기한: 2025-11-17)

DevOps / 전반

  • [ ] 커밋 메시지 자동화와 지라/컨플루언스 구조 연결 완성 (담당: DevOps, 기한: 2025-11-15)
  • [ ] 회의록과 DevLog 자동화 루틴 점검 (담당: 운영팀, 기한: 2025-11-15)

4. 회고

4.1. 잘된 점 (Keep)

  • 입국 절차를 중심으로 한 시나리오 방향이 명확히 정리되고, 클라이언트·AI 간 역할 구분과 RAG vs WebSearch 구분도 선명해졌음.
  • DevOps 환경(커밋 메시지 자동화 준비)이 구비되어 빠른 협업 전환이 가능한 상태로 정비됨.

4.2. 미진한 점 (Problem)

  • 전체 Flow 문서가 하나로 통합되지 않았고, API 스펙 역시 구두 중심이라 문서화가 필요함.
  • 캐릭터 외형/세계관 기준이 아직 정리 중으로, 팀 내 합의가 덜 된 상태.

4.3. 다음 단계 (Try)

  • 오전에는 텍스트 기반 Flow를 완성하고, 오후에는 DevOps 세팅과 클라이언트/AI 연동 구조 초안을 준비한다.
  • 주말에는 PPT 비주얼·시나리오 정교화 작업을 진행하여 월요일 리뷰에서 피드백을 반영.
