1. 개요

  • 일자: 2025-11-28 금
  • 참석: 배주백, 박종욱, 이재진, 전민우

2. 논의 요약

2.1. 주요 논의

  • 프로젝트 API 종류가 많아 사용 대상 API 선별 필요
    • API 문서 자동 생성 가능성 언급(GPT/Claude 기반)
    • 코드 통합 후 API 기준 정리 예정
    • 참고: :contentReference[oaicite:1]{index=1}
  • Step1 플레이 흐름 정리 완료
    • 그래플링 훅, 인터랙션, 스테이지 결과 처리 등 핵심 기능 구동됨
    • 참고: :contentReference[oaicite:2]{index=2}
  • Step1 결과 API 전달 방식 논의
    • 스테이지 종료 시 제출할 데이터 항목 정의 필요(시간, 오답 횟수 등)
    • 참고: :contentReference[oaicite:3]{index=3}
  • Step2~4 개발 병렬화를 위한 기반 확보
    • Step1을 기준으로 다음 단계 개발 분업 가능
    • 참고: :contentReference[oaicite:4]{index=4}

2.2. 기술 / 기획 관련 논의

  • 설문 조사 기반 인터뷰 시스템 논의
    • 로그인 후 인터뷰 리스트 3~5개 자동 생성
    • 세종학당 기준 레벨 테스트 데이터 기반 200개 샘플 생성
    • 참고: :contentReference[oaicite:5]{index=5}
  • 말하기(STT) 오류 처리
    • 음성 인식 실패·무음 시 “다시 말해주세요” 방식 결정
    • 참고: :contentReference[oaicite:6]{index=6}
  • 심사관 에이전트 상태 스트리밍 검토
    • ‘생각 중’, ‘문맥 체크 중’ 등의 중간 상태 전송 가능성 확인
    • 참고: :contentReference[oaicite:7]{index=7}

2.3. 일정 / 운영 관련 논의

  • 오전 API 통합 → 오후 시연 가능성
    • 강사진 검토 대비 간단 버전 우선 구성
    • 참고: :contentReference[oaicite:8]{index=8}
  • 주말 작업 여부
