2025-11-20 데일리 회의

1. 개요

  • 일자: 2025-11-20
  • 참석: 전체 팀
  • 키워드: 로컬 서버 세팅, UV 환경, STT/TTS, LLM, OCR, 협력 플레이, 튜터 AI, 키오스크 시나리오, 멀티플레이, 맵 구성

2. 논의 요약

2.1. 주요 논의

  • 팀 전반에 걸쳐 로컬 개발 환경(uv, venv, pyproject.toml) 구조 이해 필요
  • 백엔드 API 문서화·JWT·ORM·DB 구성 완료
  • 클라이언트는 STT → GPT → TTS 음성 파이프라인 일부 검증
  • OCR 이미지 입력 포맷(배경색·글자색·메타폼) 표준화 필요
  • 협력 플레이는 “직접 힌트가 아니라 그리드 기반 간접 힌트 시스템” 방향 논의
  • 스테이지 기획 일부가 계속 확장되어 정리 필요

2.2. 기술 / 기획 관련 논의

■ 백엔드

  • uv sync 기반 설치 절차 필요
  • STT/TTS/LLM API 단위 테스트 진행
  • OCR 이미지 형식 확정 필요
  • 사용자·코인·아이템 테이블 구성 예정

■ 클라이언트(UE5)

  • 음성녹음 → 서버 → TTS 응답 구조 검증 완료
  • 맵 콜리전/반응형 오브젝트 제작
  • 그림판 UI 데이터 저장/전송 구조 제작
  • 튜터: 스테이지 튜터 vs 개인 튜터 구조 논의

■ 기획

  • 스테이지 2 시나리오 불명확
    • 원안: 키오스크 이동
    • 대안: 협동 기반 정보 분배 구조
    • 또 다른 대안: 보물찾기식 아이템 비교
  • 스테이지 1~4 고정 구조 유지:
    1. 읽기 기반 캐리어 찾기
    2. 듣기 기반 안내
    3. OCR 기반 입력
    4. 말하기 기반 심사

2.3. 일정 / 운영 관련 논의

  • 오늘: 로컬 서버 설치 교육 / API 리뷰
  • 내일: 클라이언트–서버 API 합동 테스트
  • 이번 주 내: 스테이지 1·2 완성 목표
