251202 Daily

2025-12-02 데일리 회의

1. 개요

  • 일자: 2025-12-02
  • 참석: 배주백 외 팀원
  • 키워드: 스텝1 마무리, 문제 생성 API, 레디스 캐싱, 말하기 피드백, 리치 텍스트, 맵 충돌 작업

2. 논의 요약

2.1. 주요 논의

  • 언리얼팀: 스텝1 마무리 완료, 스텝2·3·4는 각자 담당하여 미니게임 기반 학습 구조 개발 진행.
  • AI팀: 쓰기/말하기 문제 생성, 레디스 캐싱 구조 확정, 최종 평가 방식 논의.
  • 협업 구조 정리: 문제는 사전 생성 후 레디스 저장, 클라에서는 스텝 진입 시 REST 요청으로 문제 수령.
  • 클라 내부 기획 변경: 학습 중심 구조에서 미니게임 → 학습 연결 방식으로 재조정.

2.2. 기술 / 기획 관련 논의

  • 단어 클릭 → 이미지·발음·영문 포함 리치 텍스트 팝업 구현 진행.
  • 영어는 발음 순서 매칭 문제로 프로토 단계에서는 단어 단위 팝업으로 제한.
  • 맵 충돌: 컨베이어 위 오브젝트가 회전 시 떨어지는 문제 해결.
  • 키오스크 → 쓰기 팝업 출력 연결 오류 디버깅 중.
  • 말하기 모델 변경 테스트:
    • 빠른 모델은 피드백 품질 낮음
    • 높은 품질 모델은 13초 지연 발생 → 프로토 타입에서는 4초 버전 사용 검토.

2.3. 일정 / 운영 관련 논의

  • AI팀: 문제 생성 + 레디스 저장 + 시나리오 3·4 연동 API 작업 오늘 집중.
  • 최종 평가 로직은 내일~모레 착수 예정.
  • 클라: 스텝2~4 미니게임 제작을 이번 주 핵심 목표로 진행.
  • 서버: 레디스 세팅 완료, 결과 저장 구조 확정. 엔드콜은 읽기·듣기 먼저 적용 후 확장.
  • 타 팀 상황 공유: 일부 조는 인력 이슈로 개발 중단.

3. Action Items

클라이언트 팀

  • [ ] 스텝2·3·4 미니게임 흐름 제작 (담당: 전원 분담, 기한: 12/06)
  • [ ] 리치 텍스트 기반 단어 팝업 완성 (담당: 배주백, 기한: 12/04)
  • [ ] 컨베이어·키오스크 상호작용 버그 재확인 (담당: 이치훈, 기한: 12/03)
  • [ ] 맵 작업 병행 시 충돌 방지 위한 커밋 동기화 규칙 적용 (담당: 팀 내 공통, 즉시)

AI 팀

  • [ ] 쓰기/말하기 문제 생성 API 구현 및 레디스 저장 연동 (담당: 박종욱·전민우, 기한: 12/03)
  • [ ] 말하기 평가 모델 지연 개선 테스트 (담당: 박종욱, 기한: 12/05)
  • [ ] 최종 평가(레포트) 생성 로직 설계 (담당: AI팀, 기한: 12/05)

DevOps / 전반

  • [ ] AWS/학교 서버 연결 이슈 조사 (담당: DevOps, 기한: 12/04)

4. 회고

4.1. 잘된 점 (Keep)

  • 스텝1 완성과 함께 전체 구조가 안정화되며 스텝2~4 분업 체계가 명확해짐.
  • AI팀–클라팀 간 문제 생성/전달 방식 합의로 흐름이 정리됨.
  • 리치 텍스트, 발음 팝업 등 학습 품질을 높이는 기능 개발 진척.

4.2. 미진한 점 (Problem)

  • 맵 병행 작업에서 커밋 충돌·작업 중복 위험 발생.
  • 말하기 평가 모델 지연으로 UX 저하 가능성.
  • 일부 기획이 일정에 따라 수시로 변경되어 기술 구조 반영 부담 증가.

4.3. 다음 단계 (Try)

  • 맵 작업 브랜치 분리 또는 맵2 방식으로 충돌 최소화.
  • 말하기 피드백은 프로토 단계에서 속도 우선 모델로 적용 후 추후 교체.
  • 스텝2~4를 가능한 한 단일 프레임워크(공통 UI/공통 엔드콜 구조)로 묶어 유지보수성 확보.
