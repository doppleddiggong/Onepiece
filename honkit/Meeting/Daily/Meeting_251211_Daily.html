2025-12-11 데일리 회의

1. 개요

  • 일자: 2025-12-11
  • 참석: 팀 전체
  • 키워드: UI/UX 정리, Speak API 통합, Listen Quest 보완, OCR 쓰기 테스트, 알파 준비

2. 논의 요약

2.1. 주요 논의

  • UI가 “간격·글꼴 크기 등 세세한 부분에서 어색하다”는 피드백을 받아, UI/UX 전반 재정리 작업 진행 중.

    oaicitation:1‡1211데일리 회의.txt
  • Speak API를 테스트 완료했으며, 게임 시스템 전반에 스피크 컴포넌트 통합 작업 착수.

    oaicitation:2‡1211데일리 회의.txt
  • 알파까지 진행할 모든 JIRA 태스크를 정리 완료하고 일정 기반 개발 진행.

    oaicitation:3‡1211데일리 회의.txt

2.2. 기술 / 기획 관련 논의

  • 단어 레벨 설정 시 상위 레벨 선택 → 하위 레벨 포함 생성 기능 필요성 논의.

    (레벨 2 선택 시 레벨 1 단어까지 포함해 풍성한 데이터 생성)

    oaicitation:4‡1211데일리 회의.txt
  • Listen Quest의 초기 구현은 IPC 수준이어서, 호흡·비주얼 요소 보강 필요. 작업 진행 중.

    oaicitation:5‡1211데일리 회의.txt
  • 쓰기(OCR) 테스트에서 UI 레이어·Z-Order 문제 발생. 해결을 위해 교수님 자문 필요.

    oaicitation:6‡1211데일리 회의.txt

2.3. 일정 / 운영 관련 논의

  • 발표(알파)는 다다음 주 월요일로 확정. 지금부터 티 나는 부분(가시적 품질 요소)을 우선 정비해야 함.

    oaicitation:7‡1211데일리 회의.txt
  • 메인 태스크는 목요일~금요일 내 마무리, 금요일 팀 테스트 후 귀가하는 일정으로 조정.

    oaicitation:8‡1211데일리 회의.txt
  • AI 스크립트는 로컬 환경에서 생성 중이며, 전체 흐름 점검 필요.

3. Action Items

  • [ ] Listen Quest 비주얼·호흡 요소 반영 — 담당: 은이, 기한: 12/14
  • [ ] 쓰기(OCR) UI 레이어 문제 해결(Z-Order 조정) — 담당: 치유, 기한: 12/13

AI 팀

  • [ ] 로컬 AI 기반 스크립트 생성 안정화 — 담당: 배주백, 기한: 12/14

DevOps / 전반

  • [ ] 알파 대비 JIRA 태스크 정리 및 진행률 점검 — 담당: 전체, 기한: 주간

4. 회고

4.1. 잘된 점 (Keep)

  • Speak API 연동이 빠르게 완료되어 기능 통합 단계로 진입함.
  • 알파 범위 태스크 정리로 일정 가시성이 높아짐.

4.2. 미진한 점 (Problem)

  • Listen Quest와 쓰기 UI의 기술적 디테일 부족(호흡·Z 오더 등).
  • 외부 피드백 기반 UI 정리가 예상보다 시간이 많이 소요됨.

4.3. 다음 단계 (Try)

  • 이번 주 중 UI/UX 전반 완성도 확보 후 전체 흐름 테스트.
  • 알파까지 “티 나는 부분”을 우선적으로 개선하여 시연 안정화.
  • 주 후반(목·금)에 팀 전체 기능 통합 테스트 진행.
