251208 Daily

2025-12-08 데일리 회의

1. 개요

  • 일자: 2025-12-08
  • 참석: 배주백
  • 키워드: API 구조, 스피킹/라이팅 처리, 테스트 진행, 시나리오 데이터 확인

2. 논의 요약

2.1. 주요 논의

  • API RoomID, UserID 전달 구조를 정비하여 네트워크 레이어 정돈.
  • 이를 기반으로 Speak / Write / Read / Listen 데이터 수신 구조 정리.
  • 현재 각자 개별 테스트 진행 중이며, 특히 말하기(Speaking) 파트 연동과 출력 포맷 조정 중.
  • 실제 운영 데이터가 들어오면 결과 반영 및 UI 출력까지 확정 예정.

2.2. 기술 / 기획 관련 논의

  • Read, Listen 데이터는 정상적으로 확인됨.
  • Step 3, Step 4 시나리오 데이터는 아직 미생성 상태이며, 이후 API 데이터 연동 필요.
  • 스피킹 테스트 로직은 API 붙는 단계까지 완료되었고, 실데이터 입력 후 품질 확인 예정.

2.3. 일정 / 운영 관련 논의

  • 시나리오 데이터 생성 일정이 후속 작업에 직접 영향.
  • 현재 테스트는 파트별 병렬 진행 중이며, 데이터 확정 시 UI/UX 및 평가 흐름 안정화 예정.

3. Action Items

클라이언트 팀

  • [ ] Speaking 테스트 결과 출력 정교화 (담당: 배주백, 기한: 12/09)
  • [ ] Step 3·4 시나리오 데이터 수신 대비 구조 점검 (담당: 배주백, 기한: 12/09)

AI 팀

  • [ ] Step 3·4 시나리오 데이터 생성 여부 및 스펙 공유 (담당: AI 팀, 기한: 12/09)

DevOps / 전반

  • [ ] API 구조 변경 사항 문서화 및 공유 (담당: 배주백, 기한: 12/09)

4. 회고

4.1. 잘된 점 (Keep)

  • 네트워크 구조가 정리되며 API 흐름 안정화에 한 걸음 전진.
  • 말하기 테스트 연동이 빠르게 진척 중.

4.2. 미진한 점 (Problem)

  • Step 3·4 시나리오 데이터 미완성으로 인한 후속 구현 지연 가능성.
  • 실데이터가 아직 없어 품질 검증 단계가 미뤄지고 있음.

4.3. 다음 단계 (Try)

  • 실제 API 응답 기반으로 스피킹·라이팅 출력 포맷 확정.
  • 시나리오 데이터를 활용한 멀티 스텝 진행 로직 검증.
  • UI 연결 및 사용자 피드백 루프 통합.
