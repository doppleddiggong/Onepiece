## 1. 오늘의 주요 변경
- **KLingo 네트워크 API 통합**: 기존 HTTP 네트워크 시스템을 제거하고 KLingo 네트워크 API를 도입하여 시나리오 조회, OCR 텍스트 추출, 음성 질문 응답 기능을 추가했습니다. 이를 통해 네트워크 요청 방식을 통합하고, 테스트용 네트워크 액터에 관련 API 호출과 응답 핸들러를 구현했습니다.
- **도어 및 스위치 인터랙션 기능 추가**: 게임 내 도어와 스위치 관련 인터랙션 기능을 새롭게 구현하여 플레이어의 상호작용을 보다 자연스럽게 처리할 수 있도록 했습니다. ADoor 클래스와 AWeightSwitch 클래스에 이벤트와 상태 관리 로직을 추가했습니다.
- **로그 출력 방식 개선**: 기존 UE_LOG 매크로를 PRINTLOG로 변경하여 로그 출력 방식을 통일하고, 포인터 멤버 변수에 TObjectPtr을 적용하여 안정성을 개선했습니다.
- **무게 스위치 기능 개선**: 무게 스위치의 중첩 처리 로직을 개선하여 여러 물체가 동시에 올라가거나 내려가는 상황에서 상태가 올바르게 반영되도록 했습니다.
- **상호작용 시스템 리팩토링**: 플레이어 상호작용 시스템을 도입하고 기존 인터랙션 코드를 리팩토링하여 감지 및 상호작용 로직을 개선했습니다. UInteractionSystem 컴포넌트를 추가하여 상호작용을 중앙화했습니다.

## 2. 시스템 영향도
- **네트워크 시스템**: KLingo 네트워크 API 도입으로 인해 네트워크 요청 방식이 통합되었으며, 기존 HTTP 네트워크 시스템이 제거되었습니다. 이는 네트워크 요청의 일관성을 높이고 유지보수성을 향상시킵니다.
- **게임플레이 모듈**: 도어 및 스위치 인터랙션 기능 추가로 인해 게임플레이의 상호작용 요소가 강화되었습니다. 새로운 클래스와 이벤트 시스템이 추가되어 플레이어 경험이 개선되었습니다.
- **로그 시스템**: 로그 출력 방식의 통일과 포인터 선언 방식 개선으로 인해 코드의 가독성과 메모리 관리 안정성이 향상되었습니다.
