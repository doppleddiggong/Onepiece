## 1. 오늘의 주요 변경
- **훅 시스템 물리 및 충돌 처리 개선**: 훅 시스템에서 대상 오브젝트를 끌어올릴 때 물리 시뮬레이션과 충돌을 비활성화하여 부드럽고 방해 없는 이동을 구현했습니다. 이는 사용자 경험을 향상시키고, 훅 해제 시 원래 상태로 복원되도록 하여 안정성을 높였습니다.
  
- **캐리어 정보 위젯 초기화 개선**: 캐리어의 색상과 패턴 정보를 UI 위젯에 정확히 초기화하고 표시하도록 변경했습니다. Tick 함수 내에서 지연 초기화 방식을 적용하여 정보 반영 속도를 개선했습니다.

- **인터뷰 팝업 시스템 구현**: 서버로부터 받은 인터뷰 질문 데이터를 팝업으로 표시하고, 사용자가 답변을 입력할 수 있는 기능을 구현했습니다. 이를 통해 인터뷰 콘텐츠를 효과적으로 관리할 수 있는 기반을 마련했습니다.

- **결과 팝업 타입 추가 및 매핑 설정**: 결과 팝업을 새롭게 도입하면서 이를 관리하는 팝업 타입과 클래스 매핑을 추가했습니다. 이를 통해 결과 팝업을 기존 시스템에 통합하여 활용할 수 있도록 개선했습니다.

- **인터랙션 위젯 표시 로직 활성화**: 인터랙션 시작과 종료 시 위젯이 정상적으로 표시되고 사라지도록 수정하여 사용자 경험을 개선했습니다.
