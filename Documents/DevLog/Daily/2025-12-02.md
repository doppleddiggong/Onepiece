## 1. 오늘의 주요 변경
- **결과 팝업 UI 개선**: 결과 팝업에서 단어 위젯을 텍스트 블록으로 변경하여 UI 구성을 간소화했습니다. 이를 통해 UI의 가독성이 개선되었으며, 테스트용 팝업 액터에 결과 팝업 호출 기능을 추가하여 개발 및 디버깅 편의성을 높였습니다.
  
- **미디어 재생 기능 개선**: AMoviePanel에서 미디어 재생 기능을 추가하고 초기화 과정을 정리했습니다. 이를 통해 동영상 콘텐츠의 표시 및 재생 종료 시 동작 제어가 가능해져 미디어 활용 범위가 확장되었습니다.

- **TTS 오디오 캐싱 서브시스템 추가**: TTS 오디오를 메모리와 디스크에 캐시하는 서브시스템을 도입하여 네트워크 요청을 줄이고 성능을 개선했습니다. 중복 요청 방지를 위한 로직도 추가되어 효율성이 높아졌습니다.

- **단어 팝업 기능 추가**: 단어 정보를 보여주는 팝업을 새롭게 구현하여 사용자가 단어의 발음과 뜻을 쉽게 확인할 수 있도록 했습니다. 이로 인해 사용자 경험이 개선되었습니다.

- **설문 키오스크 기능 추가**: 사용자가 상호작용할 수 있는 설문 키오스크를 구현하여 인터랙티브한 경험을 제공했습니다. 이를 통해 게임 내에서 다양한 질문을 제시하고 답변을 받을 수 있는 기능이 추가되었습니다.

## 2. 시스템 영향도
- **UI 시스템**: 결과 팝업 및 단어 팝업의 UI 개선으로 사용자 인터페이스의 일관성과 가독성이 향상되었습니다. 이는 사용자 경험에 직접적인 영향을 미칩니다.
  
- **미디어 시스템**: AMoviePanel의 미디어 재생 기능 추가로 미디어 콘텐츠의 활용도가 높아졌으며, 초기화 과정의 정리로 유지보수성이 개선되었습니다.

- **네트워크 시스템**: TTS 오디오 캐싱 서브시스템의 도입으로 네트워크 요청을 줄이고, 응답 속도를 개선하여 전체 시스템의 성능을 향상시켰습니다.

- **게임플레이 시스템**: 설문 키오스크 기능 추가로 게임 내 상호작용이 증가하고, 사용자 참여를 유도하는 요소가 강화되었습니다.

## 3. 리스크 및 문제
- **잠재적인 문제점**: TTS 오디오 캐싱 시스템의 구현이 예상보다 복잡할 수 있으며, 캐시 관리 및 오류 처리에 대한 추가적인 검토가 필요합니다.
  
- **기술적 부채**: 기존 UI 컴포넌트와의 통합 시 발생할 수 있는 호환성 문제를 해결할 필요가 있습니다. 특히, 리치 텍스트 팝업의 경우 기존 시스템과의 충돌 가능성이 존재합니다.
