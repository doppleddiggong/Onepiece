## 1. 오늘의 주요 변경
- **HowToPlay 페이지 세분화**: 기존의 HowToPlay 페이지를 퀘스트별로 세부 단계로 나누어 사용자에게 더 구체적인 안내를 제공하도록 개선했습니다. 이를 통해 사용자 경험을 향상시키고, UI 텍스처와 데이터도 추가 및 정리했습니다.
  
- **튜토리얼 단계별 HowToPlay 팝업 기능 개선**: 튜토리얼 진행 중 각 단계에 맞는 HowToPlay 팝업을 자동으로 보여주는 기능을 추가했습니다. 퀘스트 진행 상태에 따라 관련 학습 페이지를 선택해 보여주어 사용자 경험을 높였습니다.

- **페이지 인디케이터 표시 조건 개선**: 페이지 수가 1 이하일 경우 페이지 인디케이터가 불필요하게 표시되는 문제를 해결하여 UI의 깔끔함을 유지했습니다.

- **스크린샷 기능 복원 및 F1 키 기능 제거**: 스크린샷 기능을 복원하고, F1 키의 기능을 제거하여 불필요한 조작을 방지했습니다. 이로 인해 사용자 인터페이스의 일관성이 향상되었습니다.

- **로비 UI 개선**: 나침반 시스템에 거리 표시 기능을 추가하고, 로비 화면에 Back 버튼을 추가하여 사용자 내비게이션을 개선했습니다.

## 2. 시스템 영향도
- **UI 시스템**: HowToPlay 팝업 및 페이지 스크롤 뷰 시스템의 도입으로 UI 구성 요소가 변경되었으며, 사용자 경험이 개선되었습니다. 또한, 페이지 인디케이터의 동적 표시 조건 변경으로 UI의 가독성이 향상되었습니다.
  
- **Gameplay 시스템**: 튜토리얼과 관련된 로직이 변경되어 퀘스트 진행에 따른 사용자 안내가 더 명확해졌습니다. 이는 사용자 학습 효과를 높이는 데 기여할 것입니다.

- **Input 시스템**: F1 키 기능 제거 및 스크린샷 기능 복원으로 입력 처리 로직에 변화가 생겼습니다. 이는 사용자 조작의 일관성을 유지하는 데 도움을 줍니다.

## 3. 리스크 및 문제
- **잠재적인 문제점**: HowToPlay 팝업의 동적 페이지 구성으로 인해 특정 퀘스트에서 페이지 로딩 지연이 발생할 수 있습니다. 이는 사용자 경험에 부정적인 영향을 미칠 수 있습니다.
  
- **기술적 부채**: 튜토리얼 시스템의 세분화로 인해 기존 코드와의 호환성 문제가 발생할 수 있으며, 이를 해결하기 위한 추가 테스트가 필요합니다.
