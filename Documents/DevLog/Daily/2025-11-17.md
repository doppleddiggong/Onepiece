## 1. 오늘의 주요 변경
- **Confluence 자동 업로드 기능 추가 및 GitHub Actions 워크플로우 구성**
  - Markdown 문서를 Confluence에 자동으로 업로드하는 기능을 도입하여 문서 관리 효율성을 높였습니다. 이를 통해 지정된 문서 폴더 내 변경 사항을 감지하고 자동으로 Confluence 페이지를 생성하거나 업데이트할 수 있게 되었습니다.
- **GitHub Actions 웹훅 요청에 User-Agent 헤더 추가**
  - 웹훅 요청 시 User-Agent 헤더를 추가하여 서버 차단 문제를 예방하고, 웹훅 호출의 신뢰성을 높였습니다.
- **로봇 플레이어 캐릭터 및 드로잉 보드 UI 구현**
  - 로봇 플레이어 캐릭터의 기본 이동, 점프, 달리기 기능을 구현하고, 드로잉 보드 위젯을 추가하여 사용자 입력에 따른 캔버스 그리기 기능을 지원했습니다.
- **RadicalMike 캐릭터용 애니메이션과 머티리얼 리소스 추가**
  - 캐릭터의 다양한 동작과 외형 표현을 위한 애니메이션, 머티리얼, 텍스처, 메시 리소스를 추가하여 캐릭터의 비주얼 완성도를 높였습니다.
