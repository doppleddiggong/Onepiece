## 1. 오늘의 주요 변경
- **UI 정리 및 개선**: 레벨 선택 UI에서 텍스트 가독성을 높이기 위해 텍스트 크기 자동 조절 및 절삭 기능을 추가했습니다. 이를 통해 사용자 경험이 향상되었으며, UI의 전체적인 깔끔함이 개선되었습니다.
- **퀘스트 상태 자동 업데이트 기능 추가**: 퀘스트 진행 상황에 따라 QuestInfoWidget의 텍스트와 가시성을 실시간으로 업데이트하는 기능을 구현했습니다. 이를 통해 플레이어는 현재 수행 중인 퀘스트 목표를 직관적으로 확인할 수 있습니다.
- **채팅 기능 개선**: 채팅 입력 시 UI 포커스를 설정하고, 채팅 모드 전환 시 자연스러운 대화 흐름을 지원하는 기능을 추가했습니다. 이로 인해 사용자 경험이 개선되었습니다.
- **360도 방향계 UI 구현**: 카메라 방향에 따라 회전하는 360도 방향계 UI를 추가했습니다. 이를 통해 플레이어는 현재 방향을 쉽게 인지할 수 있습니다.
- **점수 데이터 타입 개선**: 평균 점수를 정수에서 실수로 변경하고, HTTP 응답에서 개별 점수 상세 정보를 포함하는 배열을 제대로 파싱하도록 수정했습니다. 이로 인해 점수 데이터의 정확성이 높아졌습니다.

## 2. 시스템 영향도
- **UI 시스템**: 레벨 선택 UI 및 QuestInfoWidget의 변경으로 사용자 인터페이스가 개선되었으며, 사용자 경험이 향상되었습니다. 방향계 UI 추가로 탐색의 편의성이 증가했습니다.
- **퀘스트 관리 시스템**: 퀘스트 상태 자동 업데이트 기능 추가로 퀘스트 진행 상황을 실시간으로 반영하게 되어, 플레이어의 몰입도가 높아졌습니다.
- **채팅 시스템**: 채팅 기능 개선으로 사용자 간의 소통이 원활해졌으며, UI 포커스 설정으로 사용성이 향상되었습니다.
- **데이터 처리 시스템**: 점수 데이터 타입 개선으로 데이터의 정확성이 높아져, 게임의 신뢰성이 증가했습니다.

## 3. 리스크 및 문제
