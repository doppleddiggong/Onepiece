## 2. 논의 요약

### 2.1. 주요 논의
- **발표 관련 질의 대응 준비**
  - “네트워크는 어떻게 처리하나요?” 질문 대비
  - 발표자료에는 포함하지 않지만 백업 설명 자료 준비함
- **시나리오 플로우 정리 공유**
  - 플로우차트 폴더 생성 및 전체 흐름 명확히 정리됨
  - 클라이언트팀은 이를 기반으로 간트차트·투두리스트 도출 예정
- **언리얼 멀티플레이 반영**
  - 가방 집기, 컨베이어 정지 등 양측 플레이어 상호작용 구조 설계
  - 퀘스트 시작/완료를 서버에 전달하는 방식 논의됨

### 2.2. 기술 / 기획 관련 논의
- **REST 기반 API 우선**
  - 소켓 미사용, REST 중심  
  - TailScale VPN으로 외부 접속 환경 확보 예정
- **필기 OCR UI**
  - 글씨 굵기/배경 등 인식률 좌우 요소 검토 필요
  - 샘플 3개 받아 테스트해보기로 결정
- **DB 스키마 설계**
  - 컬럼/관계 중심 스키마 방향 논의
  - UE 자체 DB 없음 → 마스터데이터 파일 방식 재확인

### 2.3. 일정 / 운영 관련 논의
- **프로토 발표:** 12월 8~9일 예정  
- **기획 발표:** 11월 18일  
- **간트차트 기준 모호함**
  - 러프 일정 기반인지, 실제 태스크 기반인지 멘토에게 재확인 필요
- **Jira 구조 통합**
  - AR 스페이스 → KLingo 스페이스로 통합 고려
  - Epic–Task 재정렬 및 서브태스크 타임라인 문제 확인됨
