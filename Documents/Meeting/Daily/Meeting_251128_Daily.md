## 2. 논의 요약

### 2.1. 주요 논의
- 프로젝트 API 종류 증가 → **우선순위 정리 및 문서화 필요**
- Step1 플레이 흐름 정리 완료  
  (그래플링 훅, 상호작용, 스테이지 결과 처리 등)
- Step1 결과를 서버에 제출할 데이터 구조 정의 필요  
  (시간, 오답 횟수, 정답 여부)
- Step2~4 **병렬 개발 기반 확보**

### 2.2. 기술 / 기획 관련 논의
- 로그인 후 인터뷰 리스트 자동 생성(3~5개) 구조 논의
- 세종학당 레벨 기준 기반 질문 샘플(200개) 생성 계획
- STT 오류 처리:
  - 무음·오류 발생 시 "다시 말해주세요" 방식으로 통일
- 심사관 에이전트 스트리밍 상태 검토  
  (‘생각 중’, ‘문맥 분석 중’ 등 중간 신호 전달 가능 여부)

### 2.3. 일정 / 운영 관련 논의
- 오전 API 통합 진행 → 오후 시연 가능성
- Step1 마무리 후 주말 일정 유동성 있음
