## 1. 개요
- **일자:** 2025-12-11
- **참석:** 팀 전체
- **키워드:** UI/UX 정리, Speak API 통합, Listen Quest 보완, OCR 쓰기 테스트, 알파 준비

---

## 2. 논의 요약

### 2.1. 주요 논의
- 어제 받은 피드백 중 **UI의 간격·글씨 크기 등 미세 요소가 어색하다**는 지적이 있어 전체 UI/UX 정리 작업 진행.
- Speak API가 정상 동작 확인되어 **말하기(Speaking) 시스템 통합 작업** 착수.
- 알파까지 필요한 모든 JIRA 태스크가 정리되어 **일정 기반으로 안정적 실행**을 준비.

### 2.2. 기술 / 기획 관련 논의
- 단어 레벨 설정에서 **상위 레벨 선택 시 하위 레벨 단어까지 포함되는 구조** 필요성 논의.
- Listen Quest는 초기 시연 버전이 최소 기능만 돌아가도록 되어 있어, **호흡·비주얼 요소 추가 보완 작업 진행 중**.
- 쓰기(OCR) UI는 **Z-Order(레이어 우선순위) 문제**로 표시 오류가 있어 해결 필요. 교수 자문 예정.

### 2.3. 일정 / 운영 관련 논의
- **알파 발표는 다다음 주 월요일**로 확정.  
  - 즉시 눈에 보이는 부분(가시적 완성도)을 우선 개선해야 한다는 의견.
- 이번 주 목표: **목~금에 주요 태스크 마무리 → 금요일 팀 테스트 후 귀가** 일정으로 조정.
- 로컬 AI 기반 스크립트 생성은 정상 작동 중이며, 전체 통합 전 점검 필요.
