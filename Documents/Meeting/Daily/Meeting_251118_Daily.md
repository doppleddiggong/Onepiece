## 2. 논의 요약

### 2.1. 주요 논의
- **결과창 설계 보강**  
  성공/실패 모두 피드백이 있어야 학습이 성립하며, 듀오링고처럼 “왜 맞았는지/틀렸는지”를 보여주는 구조가 필요하다는 의견 공유.
- **채팅 히스토리 저장 논의**  
  유저 간 대화(설명·정답 힌트)는 LLM 피드백/모델 개선의 근거 데이터가 될 수 있으므로 가능한 저장 선호.  
  Whisper 기반 음성·문장 쌍 데이터도 평가 지표 확보에 중요한 요소로 판단.
- **기획/시나리오 작업 범위 협의**  
  기획팀은 금일까지 내부 정리 마무리 예정. 이후 채팅/교육 시나리오 일부를 AI·기획이 함께 담당하는 형태로 조정.

### 2.2. 기술 / 기획 관련 논의
- **클라이언트 진행 상황**
  - 클라이언트 Gantt Chart 약 180개 이슈 생성 완료  
  - 이번 주 목표  
    - 로그인 API 연동  
    - REST 기반 FPI 모듈 구조 준비  
    - 주말까지 오디오 컴포넌트 테스트  
  - 서버–클라이언트 네트워크 명세서 제공 목표: 목·금
- **AI/STT/OCR**
  - Whisper Small 모델을 실제 음성+문장 데이터 세트로 테스트 중  
  - 평가 지표를 Jira에 문서화 예정
- **서버 진행 상황**
  - 로그인·토큰 발행·유저 테이블 기본 구현 완료  
  - 클라이언트에서 요청하는 “퀘스트/플레이어 상태” 데이터 정의 필요  
  - 데이터 정의를 금일 중 전달받아 테이블 설계 예정
- **Confluence 운영 통합**
  - 클라이언트 측 회의록·DevLog 전부 Confluence로 이전 완료  
  - 향후 문서 저장소는 Confluence 중심으로 일원화 예정
- **DevOps 문제**
  - GitHub 워크플로우 실행 시 MPM/NPM 반복 설치 문제 확인  
  - 캐싱 전략 재설계 필요

### 2.3. 일정 / 운영 관련 논의
- 오후 발표 진행, 이후 팀 회식  
- 오전 반차 없음 → 지각 처리되나 문서 준비는 오늘 중 마무리  
- 오늘 퇴근 전 DevLog·문서 정리는 모두 완료 목표  
- 발표 시간 중 서버/클라 데이터 정의도 진행 예정
