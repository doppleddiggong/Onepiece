## 2. 논의 요약

### 2.1. 주요 논의
- API RoomID·UserID 전달 구조 정비 및 네트워크 계층 재구성.
- Speak / Write / Read / Listen 데이터 수신 구조 업데이트.
- 말하기(Speaking) 테스트 API 연동 및 출력 포맷 조정 중.
- 실데이터 수신 후 최종 출력(UI·평가 데이터) 확정 예정.

### 2.2. 기술 / 기획 관련 논의
- Read·Listen 데이터는 정상 수신·테스트 완료.
- Step 3·4 시나리오 데이터는 미생성 상태 → 향후 API 연동 필요.
- Speaking 테스트 로직은 API 연동 완료. 운영 데이터 기반 품질 검증 예정.

### 2.3. 일정 / 운영 관련 논의

- 현재 테스트는 파트별 병렬 진행 중 → 데이터 확정 시 UI·UX·평가 흐름 안정화 예정.
